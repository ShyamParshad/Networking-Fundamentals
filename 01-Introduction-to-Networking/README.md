# Introduction to Networking

## What is Networking?

Networking is the process of connecting two or more devices so they can communicate and share data and resources with each other.

It allows devices to exchange information over a local network or the Internet.

### Real-Life Example

When I open YouTube, search on Google, or send a WhatsApp message, my device communicates with another device through a network. This communication is possible because of networking.

## Real-Life Uses of Networking

We use networking in our daily life, even if we don't notice it.

Some common examples are:

- Browsing websites
- Watching YouTube videos
- Scrolling social media
- Shopping online
- Sending emails and WhatsApp messages
- Making video calls
- Playing online games
